One letter for the day: **U** — for **unhinged**. A day that came off its rails: plans derailed, small things went sideways, and by the evening the whole day felt gloriously, honestly unhinged. Vivid, funny the moment you hear it, true to a real day — and U is its natural initial, not the obvious pick (C for chaotic), the sharper one.

## Run it

```sh
python3 main.py
```

Writes exactly one letter to `/output/entry.txt` — a single `U`, one byte, no newline.
